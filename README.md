## 🚀 Tecnologias Utilizadas
- **[Astro](https://astro.build/)**: Framework focado em conteúdo com entrega de HTML 100% estático (SSG) no primeiro carregamento.
- **TypeScript**: Tipagem estrita de configurações e tratamentos.
- **CSS3 Acessível**: Design System com alto contraste (WCAG AAA/AA), variáveis semânticas e suporte a `prefers-reduced-motion`.
- **SEO & Schema.org**: JSON-LD estruturado (`Dentist`, `BreadcrumbList`, `Article`), Open Graph e sitemap automático.

## 🛠️ Como Executar Localmente

### Pré-requisitos
- Node.js 18+ instalado

### Instalação
```bash
npm install
```

### Desenvolvimento
```bash
npm run dev
```
Acesse em: `http://localhost:4321`

### Compilação para Produção (Build Estático)
```bash
npm run build
```

### Testar Versão Compilada
```bash
npm run preview
```
